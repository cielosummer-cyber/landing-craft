01流水线

五步固定流程，每一步有完成标准，不达标不往下走。先跑通，再定制。

STEP 0 定方向 从参考卡库挑气质最接近的一张卡，或按提取协议把用户给的参考冻成新卡。禁忌栏写不出 = 还没看懂这个方向。
STEP 1 素材阶梯 CC 免费图库 → Ark 生图 → Ark 生视频 → codex 生图兜底 → 诚实 placeholder。按顺序下，不许跳级，每张肉眼审核。
STEP 2 工程级 spec 资产清单 verbatim 路径 + 全部常量写死成数值 + 行为逐条可实现。spec 里没有一个「高级感」这种不可执行的词。
STEP 3 单文件 HTML 按 spec 逐条实现，双击直开，外部依赖仅 Google Fonts 且必须带系统 fallback。内置 ?shot=1：所有入场动画立即置完成态。
STEP 4 截图验收 shoot.mjs 出首屏/中段/全页三图 + console 错误报告，对照质量门清单逐项过。0 pageerror + 评审放行，才许 open 给用户看。

03质量门与红线

截图出来后逐项过，任何一项不过 = 回去改，不交付。两条红线写在最前面。

学语法，不抄课文

从参考站只拿走令牌级语法——色板、字体配对、签名交互机制；布局结构、文案、图像、段落顺序必须是自己的。hero 构图一眼可认出同源即打回。

参考卡不含内容资产

卡里只有设计语法：色值、字阶、参数、禁忌。真实项目的文案、照片、品牌资产一律不进卡——卡可以被任何单子复用，内容不行。

PAGEERROR = 0 · SHOT=1 无隐藏态残留 · 图片全本地无 404 · IMG 同时写 WIDTH:100% + HEIGHT:AUTO
代码块显式 WHITE-SPACE:PRE-WRAP · 入场动画只有一场编排好的 PAGE LOAD · 反 SLOP：无紫渐变 / 无 EMOJI 图标 / 无编造 STATS
