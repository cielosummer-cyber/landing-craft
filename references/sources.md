# 外部页面来源目录（2026-08-20 用户指定）

按用途分四类。提取参考卡找方向时先查这份目录，不临时乱搜。

## 灵感来源（step 0 定方向 / 参考卡提取候选源）

- `collectui.com` — CollectUI，每日 UI 灵感（按组件/页面类型聚合 Dribbble  shot）
- `recent.design` — Recent，设计灵感聚合
- `mobbin.com/mcp` — Mobbin MCP，面向 AI agent 的设计参考库（真实 App/Web 截图流）
- `seesaw.website` — SEE·SAW，设计工程灵感画廊（按 Agency/AI/Crypto/Design Tools 分类，viktoroddy 视频实测使用的灵感源）

## AI 代码（构建辅助 / 对标）

- `code.minimax.io` — MiniMax Agent，AI 构建工具（对标参考：同类产品的落地页怎么做）
- `x.ai/bot` — xAI bot 页（⚠️ 有 Cloudflare 人机验证，webbridge 提取时可能撞墙，撞墙就换源）

## 组件（签名交互 / 组件配方提取源）

- `canvasui.dev` — Canvas UI，创意 canvas + WebGL 组件库
- `toolcraft.sh` — Toolcraft，AI 设计应用 starter kit
- `orbs.jakubantalik.com` — Thinking orbs，动画思考球组件（AI 产品 signature 元素）
- `originkit.dev` — Originkit，免费动画组件库
- `github.com/MengTo/threeui` — ThreeUI 开源社区版（MIT 带源码，Backgrounds 34 / Three.js 20 / Text Animation 14）。**重点提取对象：氛围背景类 shader 片段**——片段库唯一空缺品类；shader 可脱 React 壳内联进单文件；完整单文件页（如 Kage）是重场景参考实现

> 组件源的用法：看交互机制，提取**参数级配方**进参考卡的「签名交互」栏，不 copy 代码。
