# 展厅触控巨幕 参考卡（hall-touch-wall）

- 来源：公共展厅触控墙经典案例语法（Cleveland Museum of Art「ArtLens Collection Wall」多点触控墙、Cooper Hewitt 互动桌等公开案例）+ 75″ 触摸大屏项目需求提炼（2026-09-01）；深空基因为内部深空星图语法的大屏化转译——本卡的交互模型重做：**桌面鼠标视差 → 触摸直达 + 待机自演**
- 验证：demo V1「深底+发光圆点」被用户判「数字科技感不足、显低端」打回 → V2 移植体积星云+HUD 刻度体系后**用户目检通过**（2026-09-01）；字号/IDLE/涟漪参数待 75″ 现场灯下实测微调
- 气质关键词：远观仪式、巨幕星野、指尖直达、待机生息、低存在感 HUD
- 适用：博物馆 / 非遗馆 / 规划馆触控大屏、互动展墙、公共信息巨幕（4K 横屏，1.5–4m 视距，无人值守与有人点探交替）
- 不适用：手机端、桌面鼠标 dashboard、文字密集阅读页、营销转化页——巨幕的稀疏和慢节奏会压掉转化

## 色板（带角色，不临场发明新色）
- BG: `#070B12` — 展厅墨蓝（比 deep-space 的 #05080C 略抬半档：远观保住层次，LED 自发光下不发死）
- INK: `#F5EFE3` — 远读暖白（主文字）
- ACCENT: `#E3B34E` — 展厅金，唯一恒常强调色（比桌面金亮半档，LED 上不发闷）；只给当前焦点与主操作
- AURA: `rgba(227,179,78,.35)` — 焦点物光晕 / 触摸涟漪
- SEMANTIC: 青玉 `#5FA8A0` / 赭红 `#C05850` / 藤黄 `#D19A3F` / 黛蓝 `#6E93C4` — 只编码数据分类，不做装饰
- MUTED: `rgba(245,239,227,.62)` — 次要文字
- HAIRLINE: `rgba(245,239,227,.16)` — 角框 / 分隔（用量克制，大屏分区靠空间不靠线）

## 字体配对
- Display 中文: Noto Serif SC 900（fallback `"Songti SC","STSong",serif`）— 标题 ≥120px@4K（折 1080p ≥60px）
- 正文: Noto Sans SC 400/500（fallback `PingFang SC,sans-serif`）≥36px@4K（折 1080p ≥18px），行高 1.8
- Data/Label: JetBrains Mono 400 ≥28px@4K，letter-spacing .15em+
- 硬规则：任何字 <28px@4K（<14px@1080p）不许上屏——远观看不见的字等于没写

## 签名交互
- 机制：「待机生息 + 指尖直达」双态。无人时视觉自主运行：节点带相位差缓慢漂移呼吸（sin 漂移 6–10px/s）、微光巡游、每 20–40s 一次编排小高潮；**触摸即刻打断**进入交互态，无操作 30s 渐回待机。触摸反馈 = 指尖落点涟漪环（scale 0.3→2.4 / opacity .5→0 / 700ms）+ 目标磁吸高亮；点中对象 → 常驻大字详情面板（不是 tooltip）。所有信息零 hover 依赖，导航层级 ≤2
- 质感层（2026-09-01 V2 验证，低科技感打回后回填）：**体积星云着色器底**（domain-warped fbm 5 阶、冷暖两团星簇加色辉光、三层视差星野 42/60/90、终端曝光 pow(×1.55,.88) + 轻暗角 + 胶片颗粒；无鼠标故镜头改自主漫游 sin/cos 0.11/0.083）+ 5% 细网格层 + conic 雷达扫描光束 26s/圈（opacity ≤.09，#stage 必须 overflow:hidden 否则旋转角撑爆 scrollHeight）+ 玻璃面板（blur 24px + rgba(9,14,24,.58) + 金色对角角框）。节点 = 辉光核心 r24 + 虚线刻度环慢转 34s + JetBrains Mono 编号 + 近邻细连线 opacity .07；选中 = 金双环（实线+虚线各一）。**「深底+发光圆点」不够格——没有星云体积感和 HUD 刻度体系的巨幕一律算低端**
- 参数：IDLE_TIMEOUT=30s；RIPPLE=700ms；触摸目标 ≥88px@4K（≥44px@1080p）；惯性 friction .92；`cursor:none` 全场；`?shot=1` 置完成态（漂移定格、面板展开、shader 定渲 uTime≈14s 帧）

## 排版节奏
- 画布 3840×2160（开发期可 1920×1080 半尺寸等比）+ JS scale-fit；信息密度 ≤40% 占屏，单屏层级 ≤3（主视觉 / 主操作 / 注解）
- 大留白大网格：12 列、gutter ≥96px@4K；常驻操作带贴底（≤15% 屏高），四角低存在感 mono 角标
- 分区靠空间纵深（前景点物 / 中景节点场 / 远景微光），不靠卡片线框

## 图像处理
- 展品图 ≥2K 源，深色融底 + 边缘羽化（禁硬边矩形贴图）；发光描边只给当前焦点物，其余压暗至 .55
- 生成式视觉（体积星云/粒子/光带）直接当图像用，优先于照片拼贴；HUD 体系 = 四角 28px JetBrains Mono 角标（white-space:nowrap）+ 细角框括号，信息只放编号/坐标/时钟/计数

## 禁忌（这个方向做了就破功的事）
- 禁 hover 才能看到的信息——大屏没有 hover，hover 态即不存在态
- 禁鼠标指针——`cursor:none` + 涟漪替代，看见箭头就穿帮
- 禁自动出声——默认静音 + 字幕，声音由参观者主动开启（展馆安静是硬约束）
- 禁 <28px@4K 的字、禁密集注解墙——那是桌面 dashboard 的语法，不是巨幕的
- 禁滚动叙事 scrub——没人滚动巨幕；节奏由待机编排和触摸直达给出
- 禁亮底——展馆灯光下亮底 = 反光镜面 + 刺眼
- 禁把桌面 dashboard 等比放大冒充大屏——字号 / 密度 / 交互模型必须重做
- 禁二级以上深菜单——观众站着操作，30s 内必须拿到结果
