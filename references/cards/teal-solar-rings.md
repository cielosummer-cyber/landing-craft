# 黛青节令环谱 参考卡（teal-solar-rings）

- 来源：小红书视频「织造之美-北魏女性服饰解构图谱」（荒年设计 第二章），本地参考视频（12.4s / 2038×1440 / 30fps，2fps 抽帧 25 张逐帧分析提取）；姊妹卡 crimson-data-atlas（同系列第一章，语法同源、色相与交互定位不同）
- 气质关键词：黛青夜航、四时流转、同心环谱、可点读、册页藏书票
- 适用：有「周期 × 分类」双层结构的文化类知识图谱（节气物候、本草、音律、天文、历法），需要用户点选探索的数据交互首屏
- 不适用：纯展示海报页（无交互可做）、滚动叙事长页、明亮轻快的消费品牌、无分类层级的单一数据

## 色板（带角色，不临场发明新色）
- BG: `#0f1b21` — 黛青深底（可叠同色水波/冰裂纹暗纹，纹样与底明度差 8–12%）
- INK: `#ece5d3` — 米白主文字
- ACCENT: `#d9a441` — 琥珀金，只给选中态 / 小节序号 / 描金标签牌，全场唯一贯穿强调色
- TEAL: `#4ea08e` — 松烟绿，辅助撞色（环段勾线 / 流向带 / 图例辅助），全场用量 <10%
- SEASONS: 春 `#7cb56a` / 夏 `#d4694e` / 秋 `#dfa33e` / 冬 `#5e94c4` — 四季分类编码色，仅用于承载季节语义的元素（环段、节点、chip、流向带），禁挪作纯装饰
- MUTED: `rgba(158,178,182,.85)` — 次要文字（灰青）
- HAIRLINE: `rgba(236,229,211,.26)` — 分区细线 / 虚线参考环 / 标题翼线

## 字体配对
- Display 中文: Noto Serif SC 900 + `letter-spacing:.04em` + 琥珀金纯色或金→米白渐变（fallback `"Songti SC", "STSong", serif`）— 只给主标题与中心盘大字
- 英文副标题: Cormorant Garamond italic 小号（fallback Georgia），opacity .7
- Label/正文: Noto Sans SC 400（fallback `PingFang SC, sans-serif`）— 节点名 / 密集注解 10–11px
- 数字/日期: tabular-nums 衬线（Cormorant 或 Georgia）— 公历日期、角度、数值

## 签名交互
- 机制：「同心环谱点读」。SVG 三件套——中心详情盘 + 内环分类分段（**不等弧长**，弧长按所辖成员数量分配，段间留 2–3° 缝）+ 外环周期节点（等角均布，序列起点在正顶，顺时针排布）。加载编排：底纹淡入 → 标题 → 中心盘 pop → 内环分段弧依次扫入（stroke-dashoffset 全长→0）→ 外环节点沿环 stagger pop → 侧栏/图例/流向带淡入。运行态三类点读：①点外环节点 → 节点金圈高亮 + 所属内环分段提亮 + 侧栏刷详情；②点内环分段 → 所辖节点全亮 + 侧栏刷分类综述；③分类 filter chip → 异类节点压暗退场。←/→ 键沿外环步进选中。
- 参数：外环 R≈0.42×画布高，节点 r 14–18px，pop stagger 60–80ms；内环分段扫弧 500ms/段、stagger 150ms；高亮 = 金描边 2px + 柔和外发光；压暗 opacity .15–.2；`?shot=1` 全部置完成态，reduced-motion 直接完成态

## 排版节奏
- 单屏 dashboard：1600×1080 或 1920×1080（16:9，宽屏更舒展，2026-08-28 内部验证单）设计画布 + JS scale-fit；环谱为主视觉锚点居中（总直径 ≈70vh），左右信息栏贴画布两端（left/right:72），三区间隙 ≥90px 保持平衡；右栏详情侧栏（400–420px 宽），左栏导言+图例+操作说明（宽 ≤300），左下流向带，底部说明带
- 内环分段标签沿弧切线旋转（左半环翻转 180° 保持正立），禁水平硬贴在斜弧上
- 小节头格式：描金小签 + 松烟绿或金小节名 + 延伸 hairline
- 正文 10–13px 级密集注解，行高 1.7–1.9，muted 色；分区靠 hairline + 留白，无卡片无边框
- 侧栏详情结构：衬线大字名 + tabular-nums 公历日期（可带农历对照行） → 一句物候 → 一句要点 → 图鉴小图（圆形裁切 2–3 枚、≈100px + 名称 + 一句理由）

## 图像处理
- 工笔水粉/版画类素材：圆形裁切 medallion + 1px 金或松烟绿描边；奶油纸底**保留不融底**——纸色即设计元素，像册页上的藏书票（与 crimson-data-atlas 的深色融底 screen blend 正好相反，二选一看素材底色）
- 禁白底方图直接贴；禁重投影 / 强滤镜 / 描边粗细不一

## 禁忌（这个方向做了就破功的事）
- 禁四季编码色以外的分类色，也禁把季色当纯装饰用——季色是数据不是花边
- 禁照搬参考视频的完整闭环曼陀罗课文——分段弧长必须由数据决定、节点必须可点，只借「同心环解构」语法
- 禁亮底卡片 / 白色面板——一律深底 + hairline 分区
- 禁琥珀金与四季色同级抢戏——金只做选中态与标签牌（合计 <12% 画面）
- 禁滚动 scrub reveal——环谱自己长出来，然后等人点
- 禁 emoji / 3D 图标节点——统一圆点或圆形图贴的仪轨感
- 禁内环分段等弧长摆设——没有数据含义的分段不如不画
