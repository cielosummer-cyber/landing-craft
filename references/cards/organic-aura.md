# 有机光晕 参考卡（organic-aura）· ⏳ 基准卡（未验证）

- 来源：`hand-touch-omega.vercel.app`（NeuralKinetics，2026-09-07 **实地提取**：agent-browser 打开 → `eval` 抽 computedStyle + 逐屏截图存证 `/tmp/ht-*.png`）
- 证据等级：**实地提取**（色值/字号/字重/字距/圆角全部来自 getComputedStyle 实测；光晕为 WebGL 画布，参数为目测+机制推断）
- 气质关键词：柔白、有机光晕、紧字距 grotesque、胶囊 UI、呼吸感
- 适用：AI / 机器人 / 生物科技 / 医疗科技品牌页——「硬技术 + 生命感」叙事；浅色科技方向；短文案的品牌首页
- 不适用：政务/文博/深色奢华（白底柔光撑不起庄重感）；高信息密度列表页（这个方向正文只允许少量短句）；消费促销（没有购买欲）

## 色板（带角色，不临场发明新色）
- BG: `#FFFFFF` — 纯白（实测 body `rgb(255,255,255)`；柔白感来自光晕染色，不是底色本身）
- INK: `#000000` — 纯黑（标题、黑胶囊底、logo；实测无偏移）
- MUTED: `#6E6E73` — 正文灰（实测 `rgb(110,110,115)`；正文、编号标签专用）
- FAINT: `oklab(0 0 0 / 0.25)` — 标题灰词色（黑 25% 透明度，见字体配对的双色标题机制）
- PILL_BG: `#F4F4F6` — 次级胶囊底（实测 `rgb(244,244,246)`）
- PILL_LINE: `1px solid oklab(0 0 0 / 0.15)` — 白胶囊描边；黑胶囊描边用 3% 黑
- AURA: 柔焦彩虹光晕（粉/橙/青/绿 pastel，**只活在 WebGL 画布里**）——画布彩色是内容，永远不晋升为 UI 色板

## 字体配对
- Display: `Outfit` **500**（fallback `ui-sans-serif, system-ui`）`letter-spacing: -0.025em`，hero 约 `79.5px` / line-height `0.9`，section 题 `58px` / lh `0.98`
- **双色标题机制**：同一行标题里，实词黑 500、虚词/修饰词同族降 **300** + `FAINT`（黑 25% alpha）——字重和透明度的双重对比代替第二种颜色（实测「cybernetics made organic」中 cybernetics 为 300/25%）
- Body: `Inter` 400，`16–18px`，`#6E6E73`，line-height `1.45`
- Label/编号: Inter 400 `12–13px`，`#6E6E73`（「01 / Cognitive Intelligence」式编号 + 名称）
- 胶囊: 黑胶囊 Inter 500 `12px` 白字；白胶囊 Inter 400 `11.5px` 黑字

## 签名交互
- 最小演示：`demo/index.html`（零依赖双击直开，签名交互 + 排版令牌全参数；复刻提示词 `demo/PROMPT.md`）
1. **有机光晕 orb**（首选）：全宽 WebGL 画布铺在 hero 标题背后，fbm 噪声揉出一团柔焦彩虹光斑（粉→橙→青→绿 pastel），随时间缓慢漂移 + 色相缓转（目测周期 ≥20s），边缘 feather 融进白底——「技术的呼吸感」。参数：fbm 4–5 阶、色饱和度 ≤40%、漂移速度 `uv += (0.006,0.0032)·t` 量级、无鼠标交互（它自己在呼吸，不跟手）。?shot=1 时冻结在 t=固定值
2. **双色字重对比标题**（副签名，零 JS 成本）：hero 标题一行黑 500 + 一行 300/25% 灰词混排，两行以内、一行不超过 8 个拉丁词

## 排版节奏
- hero 整屏：标题块垂直居中偏上，左下放一小段 18px 灰字短文（max-width ≈ 300px），右下白胶囊标签组（`padding 14px 24px`）
- 顶栏：左 logo + 黑胶囊主按钮（`padding 4px 20px 4px 4px`，内嵌图标圆），中间浅灰胶囊导航（`#F4F4F6`，`padding 4px 24px 4px 4px`），右上次级胶囊——**全部胶囊全圆角**（`border-radius: 999px`）
- 内容节：左 section 题（58px）+ 灰字短文；右侧「01 / 名称」编号行（13px 右对齐）+ 右对齐短句标题组（Sense. / Understand. / Adapt. 式三行断句）
- 页脚：一排 Outfit 500 `16px` 黑字词汇横向铺开（领域词即导航）
- 所有分隔靠留白，全页无 hairline 无卡片

## 图像处理
- 全宽合成图像（如人机双手）`position:absolute` 整宽铺放，图像自身白底与页面融底，不用遮罩不用圆角
- 禁真实照片卡片化：图要么全宽融底，要么不放

## 禁忌（这个方向做了就破功的事）
- **禁彩色进 UI**：光晕的彩色只许留在 WebGL 画布内；按钮、标签、文字永远黑/白/灰——UI 彩色一秒变 SaaS 模板
- **禁高饱和光晕**：光晕必须 pastel 低饱和（≤40%）且缓慢变化；高饱和或快速循环 = 廉价 RGB 灯效
- **禁衬线字体**：这个方向的「有机」靠光晕和呼吸感表达，字体必须 grotesque 紧字距
- **禁卡片与阴影**：胶囊是唯一的容器形态；圆角卡片、投影浮起、玻璃拟态全部破功
- **禁长正文**：正文是 18px 灰字短句，每屏一两段；列表、表格、多列信息架构建去别的方向
- **禁深色底**：这个方向的全部价值是「白底上的呼吸感」，暗底请用 dark-tech-saas
- **禁光晕跟手**：它自己呼吸，不做鼠标视差——跟手的光斑是 dark-tech-saas 的签名，别混
