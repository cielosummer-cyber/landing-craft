# 复古消费 DTC 参考卡（✅ 已自建验证）

- 来源：drinkolipop.com（2026-08-20 提取）；验证单：内部项目（野柠柠檬气泡水，2026-08-20 验收通过）
- 验证修正：
  1. 中文 display 免费配对实测可用：**ZCOOL KuaiLe**（站酷快乐体，Google Fonts）配 Fraunces 900——补上了卡里的中文字体空缺
  2. gpt-image-2 生图中文标签渲染准确（「野柠 YELING / 海盐 SEA SALT / 青柠 LIME」一次全对）；DTC 品牌定制罐在免费图库**必然零命中**，这类单素材阶梯直接走第二级生图，别浪费时间去翻图库
  3. 提示词带页面底色色值（`#F7F3E8`）后，生成图背景与页面无缝——这个技巧对浅色底方向尤其值钱
  4. `document.fonts.check()` 不带文本参数对 unicode-range 中文字体会误报 false，验收查字体要带中文样字：`check("16px 'ZCOOL KuaiLe'", '野')`
- 气质关键词：奶油底、复古衬线、明快撞色、亲切、杂货铺感
- 适用：食品饮料、个护、宠物、生活方式消费品；要「货架上想拿起来」的品牌
- 不适用：B2B、金融、医疗严肃场景——复古俏皮撑不起信任感

## 色板
- BG: 奶油 `#F7F3E8` 系（实测导航/底为近白奶油）
- INK: 深松绿 `#034638` / `#14433D` — 标题和正文共用
- ACCENT: 柠檬黄 `#F5F36A` 级 pill CTA（Shop Now 实测为亮黄胶囊 + 深绿字）
- 顶部公告条：深绿底 + 奶油字（反色运用）

## 字体配对
- Display: 复古粗衬线 WindsorEF 900 40px+（免费替代：**Fraunces** 900，开 `SOFT`/`WONK` 轴最接近这个味道；fallback Georgia）
- UI/正文: Ano 700（免费替代：Nunito Sans / DM Sans，圆润几何无衬线）

## 签名交互
- 最小演示：`demo/index.html`（零依赖双击直开，签名交互 + 排版令牌全参数；复刻提示词 `demo/PROMPT.md`）
- 机制：产品罐/瓶视差漂浮——多个人物/产品图按不同速率随滚动上下漂移（data-speed 属性 + rAF translateY）
- 参数：speed 分三档 0.03 / 0.06 / 0.1；入场用轻微回弹 easeOutBack

## 排版节奏
- 大字短句左对齐 hero + 右半产品图；分类用描边胶囊 chip（深绿 1.5px 边，hover 填充）；曲线分隔（section 之间用波浪/弧形色块交接）

## 图像处理
- 产品图必须真实拍摄/生成（罐子实物），白底或透明底直接坐奶油底上；禁滤镜，颜色要「能喝」

## 禁忌
- 禁暗底、禁细瘦字体（这方向字必须「有肉」）、禁黑白灰性冷淡、禁直角硬边——圆角和曲线是这个方向的体温
