# hall-touch-wall 复刻提示词

> 做一面「展厅触控巨幕」首屏：展厅墨蓝底（#070B12，径向微光托中心）；3840×2160 画布 + JS scale-fit（开发期可 1920×1080 半尺寸）；中央宋体 900 巨标 ≥120px@4K（letter-spacing .12em）+ 44px 超宽字距副标；中景 12–16 个发光分类节点（青玉 #5FA8A0 / 赭红 #C05850 / 藤黄 #D19A3F / 黛蓝 #6E93C4，feGaussianBlur 辉光，只编码不装饰），远景 90 粒 5% 透明度微光星点。交互双态：待机时节点带相位差 sin 漂移（6–10px/s）呼吸，触摸任意处出金色涟漪环（scale 20→200 / opacity .5→0 / 700ms），点中节点 → 金圈高亮 + 底部常驻大字详情面板（96px 宋体名 + 38px 描述，border-top hairline），无操作 30s 面板渐隐回待机。底部操作带 3 枚胶囊大按钮（480×120、字号 40、金只给当前项），四角 28px JetBrains Mono 低存在感角标。全场 cursor:none，零 hover 依赖，`?shot=1` 定格完成态（漂移定格+面板展开）。禁忌：鼠标指针 / hover 信息 / 自动出声 / <28px@4K 的字 / 密集注解 / 滚动 scrub / 亮底 / 深菜单 / 桌面 dashboard 等比放大。
