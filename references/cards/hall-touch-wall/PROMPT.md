# hall-touch-wall 复刻提示词

> 做一面「展厅触控巨幕」首屏：展厅墨蓝底（#070B12）；3840×2160 画布 + JS scale-fit（开发期可 1920×1080 半尺寸，#stage 必须 overflow:hidden）。底层 WebGL2 体积星云着色器：domain-warped fbm 5 阶四段色（墨蓝→靛蓝→青绿→展厅金 #E3B34E 低透明度）、冷暖两团星簇加色辉光、三层视差星野（scale 42/60/90、阈值 .978/.986/.991）、终端曝光 pow(col×1.55,.88) + 轻暗角 + 胶片颗粒；无鼠标，镜头用 sin/cos（0.11/0.083）自主漫游。上叠 5% 细网格层 + conic 雷达扫描光束（26s/圈，opacity ≤.09）。中央 eyebrow（JetBrains Mono 30px 金 .5em 字距）+ 宋体 900 巨标 ≥120px@4K + 44px 超宽字距副标。中景 12–16 个分类节点：辉光核心 r24（feGaussianBlur）+ 虚线刻度环慢转 34s + mono 编号（N-01…）+ 近邻细连线 opacity .07，四色只编码（青玉 #5FA8A0 / 赭红 #C05850 / 藤黄 #D19A3F / 黛蓝 #6E93C4）。交互双态：待机时节点相位差 sin 漂移呼吸；触摸任意处出金涟漪（r20→200 / 700ms）；点中节点 → 金双环高亮 + 玻璃详情面板（blur 24px + rgba(9,14,24,.58) + 金色对角角框：mono meta 行 ID/CAT/POS + 96px 宋体名 + 38px 描述），无操作 30s 渐隐回待机。底部 3 枚胶囊大按钮（480×120、40px），四角 28px mono 角标（nowrap）+ 细角框。全场 cursor:none，零 hover 依赖，`?shot=1` 定格完成态（漂移定格 + 面板展开 + shader 定渲 uTime≈14s 帧）。禁忌：深底+发光圆点（没有星云体积感和 HUD 刻度体系一律算低端）/ 鼠标指针 / hover 信息 / 自动出声 / <28px@4K 的字 / 密集注解 / 滚动 scrub / 亮底 / 深菜单 / 桌面 dashboard 等比放大。
