# 参考卡模板

> 一张卡 = 一个被验证过的美学方向的冻结设计令牌。agent 从卡取参数，不凭空发明。
> 卡从两处来：① 本 skill 跑过并验收的单子（沉淀）；② 真实优秀页面（按下方协议提取）。
> 卡只记**可执行的令牌和禁忌**，不写感受派形容词——形容词放在「气质关键词」一栏，且不超过 5 个。

```markdown
# {方向名} 参考卡

- 来源：{项目路径或 URL}
- 气质关键词：{≤5 个}
- 适用：{什么主题/品牌调性合用}
- 不适用：{什么主题千万别用这方向}

## 色板（带角色，不临场发明新色）
- BG: {#} — {底色角色}
- INK: {#} — {主文字}
- ACCENT: {#} — {唯一强调色，贯穿全场}
- MUTED: {rgba} — {次要文字}
- HAIRLINE: {rgba} — {分隔线，如适用}

## 字体配对
- Display: {字体}（fallback {...}）— {用在哪}
- Label/Mono: {字体} — {用在哪}
- 中文: {字体栈}

## 签名交互
- 机制：{一段话说清：监听什么、算什么、映射到什么 CSS}
- 参数：{全部数值，如 R=280 / LERP=0.08 / RANGE=90vh}

## 排版节奏
- {容器宽度 / section padding / 分隔方式（hairline vs 卡片）/ 字号阶梯}

## 图像处理
- {亮度/滤镜/遮罩/圆角规则}

## 禁忌（这个方向做了就破功的事）
- {如：暗金方向禁亮底卡片；新中式方向禁粗边框}
```

## 从外部页面提取新卡的协议

1. 拿到参考（URL / 截图 / 用户描述「就要 XX 那种感觉」）
2. 有 URL：kimi-webbridge 打开 → `screenshot` 全页 + `evaluate` 抽 computedStyle（body 背景、主标题 font-family/size/weight、accent 色出现处、按钮样式）
3. 只有截图：肉眼提取色板（取色）、字体气质（衬线/无衬线/字重）、布局节奏、签名交互（如视频/GIF 则逐帧看）
4. 按模板填卡，存 `references/cards/{方向名}.md`
5. 禁忌栏必须填——写不出禁忌说明这个方向你还没看懂，回去再看
