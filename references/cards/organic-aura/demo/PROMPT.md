# 复刻提示词 · organic-aura 最小 demo

复刻 organic-aura 参考卡最小 demo：单文件零依赖 HTML（仅 Google Fonts Outfit 300/500 + Inter 400/500，带 ui-sans-serif/system-ui fallback），纯白底 #FFFFFF、纯黑 #000000 标题、正文灰 #6E6E73（Inter 400 / 18px / lh 1.45）、标题灰词 rgba(0,0,0,.25)、次级胶囊底 #F4F4F6、白胶囊描边 1px rgba(0,0,0,.15)。Display 全用 Outfit 500 + letter-spacing -0.025em，hero 79.5px / lh 0.9，section 题 58px / lh 0.98。签名交互：全宽 WebGL 画布铺 hero 标题背后，fbm 5 阶噪声揉一团柔焦彩虹光斑——radial mask smoothstep(0.64,0.16, d+(n-0.5)*0.38) 控制光团范围，配色用 pastel cos palette `0.90 + 0.16*cos(2π*(a1 + vec3(0,.33,.67)))`（a1 = 角度 + n*0.55 + t*0.08，fract 环绕），alpha = mask*(0.42+0.38n)，全程 mix 向白色保 pastel（饱和 ≤40%）；漂移 vec2(t*0.6,-t*0.35)、t=秒×0.01，自主呼吸不跟手；?shot=1 冻结 t=8.0 只渲一帧；WebGL 不可用时退化为 CSS radial-gradient 静态光晕。副签名：双色字重对比标题——一行黑 500 + 灰词 300/25% 混排（如「breathing soft machines」中 breathing 为灰词）。顶栏三胶囊（左黑胶囊主按钮 padding 4px 20px 4px 4px 内嵌白圆图标 / 中浅灰胶囊导航 padding 10px 24px / 右白胶囊 padding 14px 24px），全圆角 999px；hero 左下 12px cap + 18px 灰字短文（max-width 300px），右下白胶囊标签组；内容节左 58px 题 + 灰短文、右侧「01 / 名称」13px 编号右对齐 + 右对齐三行断句标题（感知。/ 理解。/ 呼吸。）；页脚一排 Outfit 500 16px 领域词横铺；底部 mono 参数行（ui-monospace 11px rgba(0,0,0,.35)）。禁忌：彩色进 UI（光晕色只在画布）、高饱和或快速循环光晕、衬线字体、圆角卡片与阴影、长正文、深色底、光晕跟手。
