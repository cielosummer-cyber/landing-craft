# 复刻提示词 · deep-space-atlas 最小 demo

> 用法：把下面这段贴给 agent，可复刻出本 demo 的语法骨架（令牌 + 签名星云着色器），再按单子主题替换内容。

复刻 deep-space-atlas 参考卡最小 demo：单文件零依赖 HTML，深空黑 #05080C 底（The Black Stays Black，不抬黑位伪造明亮）、米白 #F2EDE4 衬线主文字、唯一恒常 accent 夏布金 #C9A869（One Story, One Accent，编号/下行标题/徽章 chip）；语义色药草绿 #4E7A63 / 傩红 #A03A3C / 花炮橙 #D07A3A / 星蓝 #6B8CAE 只给数据节点和关系类型用、不做装饰，行 hover 用 color-mix(in srgb, var(--c) 6%, transparent) 一条变量换色；MUTED rgba(242,237,228,.6)、DIM rgba(242,237,228,.38)、HAIRLINE rgba(242,237,228,.14)。宋体 900 巨标题 2+2 主动断行（上行米白、下行夏布金，各 white-space:nowrap，fallback Songti SC/STSong），西文点缀 Cormorant Garamond italic，数据/图注 JetBrains Mono 300/400（fallback ui-monospace，数字 tabular-nums），mono 小字 uppercase + tracking .18em。容器 1180px、section padding 150px、hairline 分隔不用卡片、直角无圆角（按钮徽章可胶囊）。签名交互用 WebGL2 全屏体积星云着色器：domain-warped fbm 5 阶四段色星云（深空靛蓝→青绿→琥珀金，金色只低透明度点缀），冷暖两团发光星簇（fbm 阈值 smoothstep + 加色辉光，暖琥珀/冷星蓝），三层视差星野 scale 42/60/90、阈值 .978/.986/.991（近层视差大，闪烁 sin + exp glow 晕），连续镜头漂移 uv += (0.006, 0.0032)·t，鼠标视差 JS 侧 lerp 0.04 传 uniform，低存在感 HUD（细角框 + 10px mono 角标 + 左下参数行实时回显 MX/MY/LERP/DRIFT/T），终端曝光 pow(col*1.55, .88) + 轻暗角 + 胶片颗粒 hash。数据徽章 mono 大数字 + 小写 label，count-up 由 IntersectionObserver 触发（时长 1.4s easeOutExpo 为演示编排值，卡未冻结），?shot=1 模式必须直置终态不挂 observer（否则截图抓到中间值）。禁忌：亮底、圆角卡片、彩色渐变大面积铺、emoji、第二个恒常 accent；2D canvas 圆点连线平面星图一律不够格——视觉 DNA 是体积星云/发光星簇/空间景深/连续镜头运动/低存在感 HUD。
