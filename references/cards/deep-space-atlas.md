# 深空星图 参考卡（✅ 已自建验证）

- 来源：内部文化图谱项目分享卡图 + 其 DESIGN.md 设计系统 + 内部知识图谱架构图（2026-08-20 提取）；验证单：内部项目（个人页，同日验收通过）
- 验证修正：
  1. `?shot=1` 模式下 count-up 数字的 IntersectionObserver 必须禁用——否则截图抓到动画中间值（45,000 截成 44,956）。所有带动画终态的 JS 组件在 shot 模式都要直接置终态且不挂 observer
  2. canvas 星座在纯 headless 截图下表现良好（单帧静态即成立），但「鼠标增亮连线」要用 `?shot=1` + 手动 mouse.move 才能验证——shoot.mjs 的中段滚动顺带覆盖了
  3. 语义色 hover 着色的实现：`color-mix(in srgb, var(--c) 6%, transparent)` 一条 CSS 变量换色即可，不用写四套主题
- 气质关键词：深空、发光节点、宋体衬线、语义用色、克制
- 适用：知识图谱/数据叙事/文化科技主题；个人品牌页（建造者/研究型创作者）
- 不适用：活泼消费品牌、亲子、促销页——深空的冷和慢会压掉购买冲动

## 色板
- BG: `#05080C` 深空黑（V2 修正：比初版 #0C1210 更暗更蓝，给星云留出发光空间——"The Black Stays Black"：不靠抬黑位伪造明亮）
- INK: `#F2EDE4` 米白（衬线主文字）
- ACCENT: `#C9A869` 夏布金提亮版（主色，唯一恒常 accent；初版 #B89A62 在深空上偏闷）
- 语义色（只给数据节点/关系类型用，不做装饰，V2 提亮）：药草绿 `#4E7A63`、傩红 `#A03A3C`、花炮橙 `#D07A3A`、星蓝 `#6B8CAE`
- MUTED: `rgba(242,237,228,0.6)` / DIM: `rgba(242,237,228,0.38)`
- HAIRLINE: `rgba(242,237,228,0.14)`

## 字体配对
- Display: Noto Serif SC 900（fallback Songti SC/STSong）— 巨型中文标题
- 西文点缀: Cormorant Garamond italic — 罗马字、编号
- Data/Label: JetBrains Mono 300/400 — 数字、徽章、图注（数字用 tabular 感）

## 签名交互
- 最小演示：`demo/index.html`（零依赖双击直开，签名交互 + 排版令牌全参数；复刻提示词 `demo/PROMPT.md`）
- 机制（V2 修正版）：**WebGL2 全屏体积星云着色器**——domain-warped fbm 四段色星云（深空靛蓝→青绿→琥珀金）、冷暖两团发光星簇（fbm 阈值 + 加色辉光）、三层视差星野（闪烁 + glow）、连续镜头漂移（uv 随时间偏移）+ 鼠标视差（lerp 0.04）、低存在感 HUD（10px mono 角标 + 细角框）。终端曝光 `pow(col*1.55, .88)` + 轻暗角 + 胶片颗粒
- 参数：fbm 5 阶；星野 scale 42/60/90、阈值 .978/.986/.991；鼠标 lerp 0.04；drift (0.006, 0.0032)/s
- ⚠️ **被打回记录**：V1 用 2D canvas 圆点连线（120 节点 + 距离连线）被用户判定「颜色沉闷、没有质感」打回。**这个方向的视觉 DNA 是体积星云/发光星簇/空间景深/连续镜头运动/低存在感 HUD，不可简化为「深底 + 金色节点 + 大标题排版」**——平面点线 canvas 一律不够格

## 排版节奏
- 容器 1180px；section padding 150px；数据用 mono 大数字 + 小写 label 的徽章组合；分隔用 hairline 不用卡片；直角无圆角（按钮徽章可胶囊）

## 图像处理
- 不用照片，用生成式视觉（canvas 星图本身就是图像）；如用图，压暗融进深空底

## 禁忌
- 禁亮底、禁圆角卡片、禁彩色渐变大面积铺（星云光斑只能低透明度点缀）、禁 emoji、禁一个以上恒常 accent（"One Story, One Accent"——每个故事单元只许一个主色）
