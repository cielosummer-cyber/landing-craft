# 细笔档案门户 参考卡（✅ 已自建验证）

- 来源：`e-dunhuang.com`（数字敦煌官方门户首屏，2026-08-27 **实地提取**：kimi-webbridge 打开 → `evaluate` 抽 computedStyle + Swiper 实例参数 → `screenshot` 存证）。证据截图 `refs/hairline-archive-portal/`（e-dunhuang-hero.jpg、e-dunhuang-home-full-2026-08-27.png、e-dunhuang-home-state-02-stable-2026-08-27.png）
- 证据等级：**实地提取**（色值/字号/字重/圆角/动画时长/标签尺寸全部来自 `getComputedStyle` 与 `swiper.params` 实测，非目测取色）
- 验证单：内部项目（2026-08-27 四分库文化数字化门户，双平台同卡同题对决首用，8 条禁忌全过、pageerror 0）；对照单：内部项目（文献库一幕选图过亮破功——见验证修正 4）
- 验证修正：
  1. demo 首版被双平台对审打回：发明棕色渐变 / `hue-rotate` 装饰 / CTA hover `brightness(1.15)` 无证据 / 宣称 loop 却未实现无缝——demo 整体换用对侧审计候选（首尾克隆真无缝 loop + 5px 拖动阈值 + resistanceRatio .85）。教训：**demo 里的视觉占位也只许用卡内令牌或中性灰阶**
  2. 幽灵水印落在照片最暗区时感知趋零（.03 × RGB 0–12）——用卡时让水印部分压到中间调或主体亮区边缘，否则它只是近看彩蛋
  3. 长名降级判据：原提取写「8 字长名降到 90/70px」未说清「8 字」指中文还是拉丁字符——按拉丁字符数判（中文分库名实测最长 4 字，不触发）
  4. 选图必须**逐幕审**：每一幕的暗部都要同时托住白字标题和 idle 标签灰底（对照单文献库幕照片偏亮，白字压亮石、idle 标签文字被吃）
  5. 竖排 logo 轨道以源站源码为准：`left:calc(13vw - 3rem)`（1728 下 ≈177px）——首版卡写「96px 轨道」是误测，验证单曾把接近源码的 176px 误当漂移修回 0，以源码为准纠正
- 气质关键词：纯黑、极细笔画、幽灵水印、门户索引、等宽切分、人工择路
- 适用：多分库/多子站的**文化数字化门户首屏**（资源库 + 素材库 + 专题 + 文献库这类并列入口）；博物馆/档案馆/研究机构的「选择你的入口」页；分库导航即内容的场景
- 不适用：单一叙事的长滚落地页（这方向的骨架是并列切分，没有「往下读」的动线）；消费品/活动页（极细字在小屏和低分辨率投屏上直接消失）；正文密集的资讯站；单一对象无需分流的专题页

## 色板（带角色，不临场发明新色）
- BG: `#000000` — **纯黑**（实测 body `rgb(0,0,0)`；这张卡的黑是「影院黑幕」，靠它托住满幅照片，不是暗夜氛围底。源码前置 `#eee` 已被覆盖，不得采用）
- INK: `#FFFFFF` — 纯白（标题/副题/竖排 logo/标签文字统一纯白，实测无暖白偏移）
- ACCENT: `#B81010` — 深绛红，唯一强调色（实测 `rgb(184,16,16)`；只出现在 CTA 胶囊底 + 当前分库标签底 + 「新」圆徽标）
- TAB_IDLE: `rgba(208,206,204,0.32)` — 未选中标签底（冷灰半透，压在照片上仍可读）
- HAIRLINE: `rgba(255,255,255,0.20)` — 索引段之间 1px 分隔线
- WM_INK: `rgba(255,255,255,0.03)` — 幽灵水印色（白字 3% 不透明度，见签名交互）
- FOOTNOTE: `#3E3E3E` — footer 低存在感版权/元信息专用，不得拿来做正文
- 反转态：`#FFFFFF` 底 + `#000000` 字 —— CTA 与 idle 标签的 hover 在 `.2s ease-in-out` 内反转为白底黑字（700），不增加第二个彩色强调色

## 字体配对
- Display 中文: `Helvetica Neue`/Helvetica/Arial（fallback `PingFang SC`）**300**，100px，line-height 1.0 — 分库中文名。长名降到 90px（判据见验证修正 3）
- Sub 西文: 同族 **100**（Thin），80px，letter-spacing 5px，padding-left 50px — 英文副名。长名对应降到 70px
- 竖排 logo: 同族 300，20px，letter-spacing 4px（≈0.2em），`writing-mode: vertical-rl`；内嵌 span 16px/400/letter-spacing 2px，下接 1px × 40px 白线
- **幽灵水印专用**: 声明 `Playfair Display` **900**，361.2px（= 42vh @860px 高），line-height 300px —— ⚠️ 源站**只声明未加载**（无 @font-face / 字体资源，实测回退系统衬线），demo 同样只声明不加载。这是唯一允许出现衬线的地方
- CTA / 标签: 同族 400，18px；CTA `border-radius 40px` / `padding 20px 30px`
- ⚠️ 全站无 Google Fonts 中文；中文靠系统无衬线兜底（computedStyle 未暴露具体中文字体文件），这是它「细」得住的前提——不得虚构「敦煌字体」

## 签名交互
- 最小演示：`demo/index.html`（零依赖双击直开，签名交互 + 排版令牌全参数；复刻提示词 `demo/PROMPT.md`）
1. **巨型幽灵水印分库切换**（首选）：每个分库幻灯片自带一层与标题同文的巨型水印——`Playfair Display 900 / 361.2px / line-height 300px / opacity 0.03`，`position:absolute; left:100px; top:430px; transform:translateY(-430px)`，父容器 `overflow:visible` 让它出血到画布外，层级压在满幅照片之上、前景文字之下。切换分库时照片横向滑动，水印随本片一起走位——巨字读作「地层/索引编号」，不是装饰。参数：`WM_SIZE=361.2px`、`WM_LH=300px`、`WM_OPACITY=0.03`、`WM_OFFSET=(100px, -430px)`
2. **四分库等宽标签条**：索引轨桌面宽 75%（1728 下 = 1296px）、`right:0`、`bottom:50px`、高 127px，切成 **4 等份**，每格 `324px × 90px`、上距 10px，居中双行（中文名 + 英文名），未选中 `rgba(208,206,204,.32)`、相邻格 1px 白色 20% 分隔线，当前项**整格填实** `#B81010` + `padding:5px 0` 上抬 5px，`transition: all 0.2s ease-in-out`。等宽 4 格撑满容器就是这个门户的骨架，不是分页器
3. **主轨参数集**（Swiper 实例实测）：横向 slide / `speed=300ms` / `spaceBetween=10px` / `loop=true`（首尾克隆无缝）/ 拖动 `threshold=5px` / `touchRatio=1` / 边界 `resistanceRatio=0.85` / `touch-action:pan-y` / `simulateTouch=true`。**无 autoplay**——人工择路，选择权留给观众。标题入场 `fadeIn 1s ease-out .6s both`，非当前场景强制 `opacity:0` + 取消动画

## 排版节奏
- 首屏定高 `860px`（实测 1728×860，约 16:8.3），满幅照片出血铺底，**无遮罩无渐变压暗**
- 内容块 `position:absolute; left:~27vw (474.75px/1728); top:350px; z-index:2`，偏左反对称
- 副题左侧留 `padding-left:50px` 的空轨（视觉上给巨字让出起笔位）
- 竖排 logo 轨道：`left:calc(13vw - 3rem)`（验证修正 5），`top:~107px`，`z-index:2`
- 标签条贴底：索引段底边距视口底 50px，其下还有一条 65px 高的 footer 元信息带（`#3E3E3E` 小字右对齐）
- 字号阶梯极陡：361px 水印 → 100px 标题 → 80px 副题 → 18px 标签，中间**故意没有中号字**

## 图像处理
- **照片满幅 `object-fit:cover` 直出，`filter:none`、`opacity:1`**（实测），不压暗不加滤镜不加圆角——黑来自画布四周，不来自图本身
- 选图要求：主体本身就在暗处（洞窟/壁龛/夜景），自带大面积深色区域托住白字；靠选图而非后期。**逐幕审核**——每一幕的暗部都要同时托住标题白字和 idle 标签灰底（验证修正 4）
- 照片内容色（壁画矿物蓝/赭石/青绿）属于内容，不自动晋升为 UI 色板；UI 永远只有黑、白、绛红、玻璃灰
- ⚠️ 源码注释块里的 `#0848A2 / #B1430B / #076745` 是废弃旧方案，不是当前证据，禁止捡回
- 格式 `.webp`，CDN 直供

## 禁忌（这个方向做了就破功的事）
- **禁自动轮播**：原站没有 autoplay，这个方向的仪式感来自观众主动选择入口
- **禁压暗 hero 图**：本卡照片实测 `filter:none / brightness 1`。想做「聚光点亮」请改用 `digital-heritage-immersive`——两张卡在这一点上正相反，混用就两边气质都碎
- **禁宋体/衬线做中文巨标题**：serif 900 是碑刻感（另一张卡的 DNA）。这里中文巨标题必须极细无衬线；衬线**只**允许存在于 3% 的拉丁水印层
- **禁加粗**：中文标题字重 ≤300、副题 100。一旦 500+ 立刻变政务门户，「细」是这张卡唯一的贵气来源
- **禁把水印调到可读**：`opacity` 上限 0.03。≥0.08 就从「地层」变成「壁纸」，开始和标题抢戏
- **禁居中对称构图**：内容块偏左约 27vw，左侧竖排轨道必须留
- **禁第二个强调色**：只有 `#B81010`，只准出现在 CTA 胶囊底、当前标签底与「新」徽标；金/青/朱砂一律不进这张卡
- **禁标签条不等宽或超过 4 项**：等宽 4 格撑满是骨架；5 项以上请换 `digital-heritage-immersive` 的竖栏手风琴
- **禁纯黑底长正文**：这套字重在纯黑上排段落直接糊掉，本卡只承载「入口级」短文本
- **禁 spotlight / 星云 glow / 粒子 HUD**：分别撞 `digital-heritage-immersive` 与 `deep-space-atlas` 的既有签名
- **禁照搬数字敦煌的真实壁画、Logo、入口名称与构图**：只迁移色板、排版比例和联动索引机制
