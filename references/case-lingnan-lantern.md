# 案例拆解：小红书小程序「岭南灯愿」（佛山彩灯）

> 来源：用户手机录屏 4'12"（`/Users/zhouying/Downloads/ScreenRecording_08-25-2026 02-10-49_1.MP4`，1320×2868@60），
> 2026-08-24 逐帧拆解。入口海报：`xiaohongshu.com/s/poster?...miniTool/6a894927e424b80015cf53db`。
> 性质：非遗题材 UGC 互动小程序——**文化内容 + 仪式化交互 + 情感 UGC** 的完整闭环，对数字非遗/展厅交互类工单是直接对标的满分级案例。

## 一、产品结构（三栏目 + 一条仪式主线）

- **灯馆**（浏览认识）：地域花灯轮播 + 灯谱（分面筛选）
- **灯艺**（工艺学习）：制作工序 + 纹样谱
- **灯海**（情感 UGC）：满河灯火，每盏灯是一个陌生人的公开愿望
- 主线仪式四步 wizard（顶部长条步骤指示）：**选灯 → 选愿 → 心愿 → 点亮**，完成后「投入灯海」汇入 UGC 池

## 二、逐段交互拆解

### 1. 灯馆轮播（0–36s）
- 每盏灯 = 一个真实非遗项目（佛山彩灯/东莞千角花灯/高明花灯/乐安花灯/潮州花灯/忠信花灯/增城花灯/大良鱼灯）
- 版式公式：**书法感标题 + 三级地域标签（广东·佛山·广府）+ 开光形窗（海棠形/圆形）内衬古画底纹 + 插画级精绘灯体居中 + 底部一句策展文案 +「认识这盏灯 →」CTA**
- 深暖棕底 + 漂浮微尘粒子（暗场氛围粒子，密度极低）
- 左右箭头切换 + 底部小圆点指示器
- 文案示例：「祖庙秋色赛会上，头牌灯一出，满城灯头皆失色」——一句一个画面，不堆术语

### 2. 灯艺（工艺页）
- 「如何制成」工序卡：扎架 → 造型 → 装饰 → 绘制 → 装灯，每步配**线稿插画 + 米色纸卡 + 一句话要点**（「选老竹破篾，火烤定型，扎出灯骨」）
- 「纹样谱」字典：鱼/莲花/牡丹/祥云/醒狮/回纹，每纹样配吉祥语（「年年有余，水路顺遂」）——把装饰元素知识化、可查化

### 3. 灯谱（分面筛选，~200s）
- 四维分面：地域（广府/潮汕/客家/珠三角/水乡）× 造型（宫灯/鱼灯/莲花灯/动物灯/人物故事灯）× 寓意（平安/团圆/事业/学业/姻缘/健康/思念）× 工艺（彩扎/剪纸/彩绘/贴金/刺绣/木作）
- 结果卡带「国家级非遗」徽章
- 微交互说明文案直接写在页面上：「悬停或按住，花灯会先亮一角给你看」——**用文案教交互**
- 标题「按谱寻灯」：把筛选器包装成有文化感的动作

### 4. 祈愿 wizard（88–128s）★ 核心 ritual 设计
- **步骤 1 选灯**：「从刚才认得的灯里，挑最合心意的一盏」——wizard 与浏览行为勾连，不是孤立表单
- **步骤 2 选愿**：8 个单字愿望类目（安/圆/学/业/康/新/谢/念），每字配双行注解；另有「灯面一字」选择器（福/安/喜/愿/顺/圆/宁）——**选的字会写到灯面上**，后续愿望卡里显示「灯面一个『安』」，前后呼应
- **步骤 3 心愿**：双输入框——「我希望……」（占位文案即示例：「愿所念之人，岁岁平安」，限 120 字）+「我愿意为它做的一件事是……」（选填）。点睛文案：「第二件事不是功课，是让心愿从寄托落到脚下的路」——**把许愿从空想引向行动承诺**
- **步骤 4 点亮**：「以指为火，长按灯芯，待光慢慢亮起」——**长按手势模拟点火**，灯体从暗到明渐变发光；点亮后显示愿望摘要 + 「灯火已明，愿你带着这份心意继续向前」+ 双 CTA「保存为图片 / 投入灯海」（保存图片 = 自发传播物料）

### 5. 灯海（128–160s）★ UGC 场景化
- 场景：夜景水乡长卷（类《姑苏繁华图》夜版），河面/屋檐漂浮发光灯笼，每个光点 = 一份匿名公开愿望
- 顶部文案：「每个光点，都是一份匿名点亮的公开灯愿。点一盏，读一读；投一次『添灯火』，为它续一分光。」
- 点灯读愿：底部滑出卡片 = 灯缩略图 + 愿望类目 + 愿望正文 + 出处行（「一盏忠信花灯 · 灯面一个『安』 · 匿名」）+ 灯火计数 +「添一次灯火」按钮
- **「添灯火」替代「点赞」**：互动 mechanic 完全包裹在题材语义里
- 底部治理小字：「灯海无排行，灯火不论值，许愿经审核方入河」——反流量焦虑设计 + 内容审核声明，展厅/公共项目尤其要学

## 三、可复用配方（进 landing-craft 通用库）

1. **仪式四步法**：任何「参与型」交互都可套——选物 → 选意 → 留言 → 点火/发布。关键不是步骤，是每步都有题材语义包装（选灯不叫「选择灯笼」叫「选一盏灯，灯面一个字」）。
2. **开光构图**：异形窗（海棠/圆/扇）+ 古画底纹 + 主体物，非遗/中式题材的 hero 万能版式。
3. **单字类目 + 双行注解**：信息密度低但仪式感强，适合触屏大屏的类目导航。
4. **mechanic 语义化**：点赞→添灯火、发布→投入灯海、浏览→按谱寻灯。命名即氛围。
5. **行动承诺字段**：UGC 表单加「我愿意为它做的一件事」，把情绪转化成行为，文案要兜底（「不是功课，是……」）。
6. **占位文案即示例**：输入框 placeholder 直接给满分级示例，降低创作门槛。
7. **反排行声明**：公共文化项目的 UGC 区，明示「无排行、不论值、经审核」，规避攀比和运营风险。
8. **保存为图片**：每个情绪高点都给一个可带走的物料，等于自传播渠道。

## 四、对宜春非遗大屏的直接映射

- 详情页文末「互动体验·展项联动入口（预留）」→ 可落一个**简化版点灯**：选中当前非遗项目对应的吉祥物/器物 → 长按点亮 → 留一句观展心愿 → 汇入「万象生春」心愿墙（本地存储，无需后端审核可先单机）
- 五栏导航的单字化改造暂不动（现有命名已验收），但**详情页 CTA 命名**可语义化：不叫「了解更多」而按项目题材起名
- 开光构图可用于详情页 hero 的备选方向（当前官网照片方案不变，作为无图项目的兜底版式）

## 五、红线提醒
- 该案例视觉是「深暖棕 + 烫金 + 红灯笼」的**暖暗调**；宜春项目是「夏布植物染」的**浅淡克制调**。学交互结构和文案方法，不学配色。
- 长按点火、粒子、水面倒影这类动效在展厅大屏上要测性能，1920×1080 Chromium 下先验证帧率再上。
